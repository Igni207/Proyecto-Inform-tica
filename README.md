# Proyecto-Inform-tica
Proyecto de primer año de introducción a la Informática/Programación
IMPORTANTE
-Lean los comentarios que dejen los demás.
-Traten de descargar o crear copias del proyecto, no trabajen sobre el mismo github, podemos perder
todo si nos equivocamos.
-Suban las cosas donde corresponde, si usan la carpeta "Proyecto Informática", que es la Base por ejemplo, pueden añadir un archivo
BASE para el personaje, pero no uno con interacciones, ya q todavía no tenemos nada.
-Si tienen algo que ya pueda interactuar con otros códigos subanlo en carpetas aparte.
